# hxyfront-62011 马术蹄铁修整档案

源提示词编号：6

做一个面向马术俱乐部蹄铁师的修蹄记录前端项目，可以记录马匹编号、步态问题、蹄形评估、蹄铁类型、钉位、修蹄日期、下次复查日期和照片备注。页面需要有马匹列表、复查提醒、左右前后蹄对比记录、异常步态标记和蹄铁更换历史。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62011

## 装蹄质保模块

在原有修蹄档案基础上补建装蹄质保：

- **装蹄登记**：每次装蹄登记锻件编号、蹄位（左前/右前/左后/右后）、装蹄日期与保修截止日，同时出库一件库存。
- **索赔规则**：马主按「马号 + 锻件编号」申诉松动/裂纹，核对原装蹄与保修截止日；过期或编号对不上的申诉退回并留档；同一块锻件（同编号批次）未结索赔只有一笔。
- **锻件停用**：停用后该编号标为停用、库存同编号件封存（停止出库），所有已装马匹进入检换名单；原装蹄记录与历次处理事件不改动，仍按马号可查。
- **记录查询**：装蹄列表按马号、锻件编号、检换状态（待检换/已更换/未列入）筛选；马号档案含原装蹄、索赔与只追加的处理时间线。

### 分层结构

- `src/domain/` — 判断层（纯 TypeScript）：类型、装蹄/申诉/结案/停用/检换规则、筛选与马号档案查询，不依赖 React / 浏览器。
- `src/archive/` — 存档层：localStorage 读写与演示数据装载，只负责持久化。
- `src/pages/` — 页面层：React 组件（装蹄与申诉、质保记录、停用与检换、按马号查档），只调用 domain 规则并通过 archive 保存。
